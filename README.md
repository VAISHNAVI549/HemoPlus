📌 About HemoPlus
HemoPlus is an Android application I built during my undergraduate studies with the motivation to solve a real-world challenge: making blood donation easier, faster, and more accessible.
The app connects donors and recipients through a simple and user-friendly platform, helping people request or donate blood in urgent situations. It manages user registration, blood request workflows, donor search, history tracking, and profile management, with a goal to create a reliable digital ecosystem for saving lives.
✨ Key Features
🔐 User Authentication & Profiles – donors and recipients with role-based functionality.
🩸 Blood Requests & Matching – create, track, and fulfill requests with urgency and blood type filters.
📊 Dashboards & History – view donation history, requests, and statistics with interactive UI.
⚙️ Database Integration – local storage and management of user sessions and requests.
📱 Modern Android UI – XML-based layouts with intuitive navigation.
🛠️ Tech Stack
Languages: Java, XML, SQL
Frameworks & Tools: Android Studio, SQLite (local DB), Material Components
Other: Git, CardView, Session Management
